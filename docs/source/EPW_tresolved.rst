Time resolved EPW
====================================

This example demonstrates fitting time-resolved data for EPW data and the input deck can be used as a starting point or similar data. 

To run this example, download the data and the decks and the run the code in ``fit`` mode. The output is also provided in the zip file in case you want to make sure you get the same results.
